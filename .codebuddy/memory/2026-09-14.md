# 2026-09-14

## 飞书周报未推送问题 — 已解决
- 原因：用户没有在微信开发者工具里单独「上传触发器」，定时触发器 `dailyReport8PM` 从未在云端创建。
- 解决：右键 `cloudfunctions/dailyReport` → 上传触发器 → 测试通过，日报可正常生成。
- 经验：微信云函数部署后，config.json 里的 triggers 不一定随之创建/更新，改触发器后需单独「上传触发器」。
